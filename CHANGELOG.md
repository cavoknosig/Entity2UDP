# Changelog

## 1.0.1

- Added the Hubs & protocols category for Home Assistant Marketplace.

## 1.0.0

First packaged 1.0 release of Entity2UDP.

- Manage multiple UDP destinations from one Home Assistant panel, with an optional sidebar shortcut.
- Search, group, translate and pause forwarding rules without losing their configuration.
- Send on state changes or enable periodic resends, with per-destination and per-rule filtering.
- Filter recent resend summaries and errors by destination in Activity.
- Download and restore rules as JSON. See the README for installation, upgrade and troubleshooting.

## 0.5.4

- Removed the polling control from Entity2UDP Settings.

## 0.5.3

- Added an Activity tab with recent resend summaries, UDP send errors and destination reload failures.
- Added destination and event-type filters for Activity.
- Explained Home Assistant polling and periodic UDP resends in Settings.
- Updated installation, upgrade, rule configuration, backup and troubleshooting documentation.

## 0.5.2

- Consolidated sidebar visibility and Home Assistant system options in the management panel’s Settings tab.
- Added configurable page size and a destination shortcut to the filtered rule grid.
- Improved spacing and alignment in the destination and rule editors.

## 0.5.0

- Added the cross-destination Configured entities view with search, grouping and sorting.
- Added per-rule forwarding switches to pause and resume sends without deleting rules.
